# 🧠 Mental Health Prediction ML

### Machine Learning–Based Mental Health Prediction System

A **Machine Learning web application** that analyzes student-related social media and lifestyle factors to predict mental-health-related outcomes using a trained classification model.

The project combines **data analysis, machine learning, model deployment, and a web interface** into a complete end-to-end ML application.

---

## 🚀 Live Demo

🔗 **[Try the Live Application](https://mental-health-prediction-ml-n9kx.onrender.com/)**

---

## 🎯 Project Objective

The goal is to build a data-driven system that can identify patterns associated with mental health using factors such as:

- Social media usage
- Academic/lifestyle factors
- Student-related behavioural indicators
- Other relevant features from the dataset

The prediction is intended for **educational and analytical purposes**, not medical diagnosis.
